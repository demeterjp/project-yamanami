## What is Yamanami?

Yamanami is an interactive training app focused on recognizing Japanese characters and numbers more naturally and instinctively.

The goal is to build fast, automatic recognition through repeated practice.

---

## Hiragana & Katakana

Both Hiragana and Katakana are divided into three difficulty levels:

- **Easy** — Basic Hiragana/Katakana characters.
- **Medium** — Basic characters + dakuten and handakuten.
- **Hard** — All Hiragana/Katakana characters, including yōon combinations.

---

## Practice Modes

### Normal

A straightforward practice mode without a time limit.

### Kana Rush

A timed challenge where you answer as many kana as possible before the time runs out.

### Speed

A practice mode where you are given a sequence of randomly selected kana and must type all of them correctly as quickly as possible.

### Kana Fall

An arcade-style recognition exercise where kana fall down the screen and must be recognized before they reach the bottom.

### Custom Drill

Choose how many digits you want to practice, from 1 to 10.

Practice number recognition in two directions:

- **Arabic → Japanese** — Type the Japanese reading in romaji.
- **Japanese → Arabic** — Type the number using Arabic numerals.

### Survival Count

A progressive number-recognition challenge with 3 lives.

Practice in either direction:

- **Arabic → Japanese** — Type the Japanese reading in romaji.
- **Japanese → Arabic** — Type the number using Arabic numerals.

Numbers become longer after every 5 correct answers.

## About the Project

Yamanami is my first web project.

By the time I created this project, I was a third-year dentistry student and wanted to learn Japanese characters and numbers in a way that suited how I wanted to practice them. I couldn’t find exactly the kind of practice I was looking for, so I decided to build it myself.

This project has also been a way for me to learn web development by building something from scratch. As my first project, it isn’t perfect, and there are areas that could be improved. However, working on Yamanami has helped me understand what I would approach differently in future projects.
