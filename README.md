# Yamanami (山波)

Japanese learning app for mastering Hiragana and Katakana.

## Features

- Hiragana
- Katakana
- Easy / Medium / Hard
- Normal Mode
- Speed Mode
- Kana Rush
- Kana Fall

## Note

The application is designed for desktop use. It can be opened on mobile devices, but it is not fully functional.

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
