# Yamanami (山波)

Japanese learning app for mastering Hiragana and Katakana.

## Features

- Hiragana
- Katakana
- Easy / Medium / Hard
- Normal Mode
- Speed Mode
- Kana Rush

## Note

Designed for desktop use. Mobile compatibility is not fully supported.

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
